# KSPLosketPatches
Planet pack dust patches for the LosketPatches Mod for KSP

A folder you can put in your GameData folder that should load the dust colors for planets from other planet packs that users may have installed. The folder also includes optional english-translated config files for Losket, just drop in GameData and overwrite if you so choose. Every color was derived from the actual HeightColorMap terrain values in each body’s Kopernicus config if available from the mod's github repo.
